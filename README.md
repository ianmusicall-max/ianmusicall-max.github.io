# Salud y Metabolismo · el sitio

Este repo es la salida de `src/sitio.py` del proyecto `nutricion`: GitHub Pages
lo sirve tal cual. **No se edita a mano**: cada hora, después de publicar en
Facebook, el servidor reconstruye el sitio entero con los posts publicados y
lo sube acá. Un cambio hecho directamente en estos archivos se pisa en la
siguiente corrida.

Para cambiar el diseño, el texto fijo o las páginas de privacidad, sobre y
contacto: `src/sitio.py` y `assets/sitio/estilo.css` en el repo `nutricion`.
Cómo se prende y qué pide AdSense: `DEPLOY.md` de ese repo, sección
"El sitio web y AdSense".
